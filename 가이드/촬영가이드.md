# 릴스 촬영 가이드 (공통)

편집은 자동으로 처리하니까, 촬영할 때는 **아래 6가지만** 지키면 돼요.

## 꼭 지킬 것

| # | 규칙 | 이유 |
|---|---|---|
| 1 | **세로로 찍기** | 가로로 찍으면 9:16으로 자를 때 화면 절반이 잘려요 |
| 2 | **4K로 찍기** (설정 → 카메라 → 비디오 녹화 → 4K 30fps) | 편집에서 클로즈업을 자동으로 만들 때 화질이 안 깨져요 |
| 3 | **한 장면에 8~10초 이상** 찍기 | 편집할 여유가 생겨서 컷이 급하게 넘어가지 않아요 |
| 4 | **녹화를 시작하고 2초 뒤에 동작 시작**, 동작이 끝나고 2초 더 찍기 | 앞뒤가 잘리지 않아요 |
| 5 | **손이 계속 뭔가 하게** (까기, 붓기, 젓기, 집기) | 움직임이 있어야 정지 사진처럼 안 보여요 |
| 6 | **소리 켜둔 채로** 찍기 (음소거 X) | 까는 소리, 붓는 소리, 지글지글 소리를 살려요 |

## 하면 좋은 것

- 📱 **거치대**로 폰 고정. 탑샷(위에서 내려다보기)이면 1만 원대 거치대로 충분해요
- ☀️ **창가 자연광**. 형광등 바로 아래는 그림자가 지고 색이 칙칙해져요
- 🧽 찍기 전에 **렌즈 한 번 닦기**. 뿌연 화면의 원인 1순위예요
- 🛍️ 비닐봉지는 벗기고 찍기. 그릇이나 접시에 담으면 훨씬 깔끔해 보여요

## 안 해도 되는 것 (편집에서 자동 처리)

- ❌ 클로즈업 따로 찍기: 4K 원본에서 자동으로 잘라 써요
- ❌ 효과음, BGM: 편집에서 자동으로 넣어요
- ❌ 밝기, 색 보정
- ❌ 자막, 가격카드
