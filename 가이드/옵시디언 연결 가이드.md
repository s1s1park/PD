# 옵시디언 연결 가이드

GitHub 리포(`s1s1park/PD`)를 옵시디언 보관함으로 열어서, 핸드폰·PC·Claude가 같은 파일을 보게 만드는 방법이에요.

```
📱 핸드폰 옵시디언  ⇄  GitHub  ⇄  💻 PC 옵시디언
                       ⇅
                   🤖 Claude Code
```

> ⚠️ 이 보관함은 **옵시디언 Sync를 켜지 마세요.** Sync와 Git을 같이 쓰면 파일이 꼬여요. 동기화는 Git이 담당해요.

---

## 0단계. GitHub 접속 열쇠(토큰) 만들기 — 핸드폰용

핸드폰 옵시디언이 GitHub에 접속하려면 열쇠가 필요해요. (PC는 1단계 방법을 쓰면 필요 없어요)

1. 브라우저에서 GitHub 로그인 → 오른쪽 위 프로필 사진 → **Settings**
2. 왼쪽 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. 입력:
   - Token name: `obsidian`
   - Expiration: 1년 (만료되면 다시 만들면 돼요)
   - Repository access: **Only select repositories** → `PD` 선택
   - Permissions → Repository permissions → **Contents: Read and write**
4. **Generate token** → 나온 열쇠(`github_pat_...`)를 복사

> 🔒 토큰은 비밀번호예요. **채팅창이나 다른 곳에 붙여넣지 말고** 옵시디언 설정에만 넣으세요. 이 화면을 벗어나면 다시 볼 수 없으니, 옵시디언에 바로 넣는 게 좋아요.

---

## 1단계. PC 설정 (GitHub Desktop 사용 — 가장 쉬움)

1. **GitHub Desktop** 설치: https://desktop.github.com → GitHub 계정으로 로그인
2. **File → Clone repository** → `s1s1park/PD` 선택 → 저장 위치 정하기 (예: 문서 폴더) → **Clone**
3. 옵시디언 실행 → **보관함 열기 → 폴더를 보관함으로 열기** → 방금 받은 `PD` 폴더 선택
4. 설정 → **커뮤니티 플러그인** → 제한 모드 끄기 → 찾아보기 → **Obsidian Git** 설치 → 활성화
5. Obsidian Git 설정:
   - **Pull on startup** (시작할 때 최신 내용 받기): 켜기
   - **Auto commit-and-sync interval** (자동 저장 간격): `10` (분)
6. 설정 → **템플릿**(코어 플러그인) 켜기 → 템플릿 폴더 위치: `템플릿`

> Windows에서 Obsidian Git이 "git을 찾을 수 없다"고 하면 https://git-scm.com 에서 Git을 설치하고 옵시디언을 다시 켜세요.

---

## 2단계. 핸드폰 설정 (아이폰/안드로이드)

1. 옵시디언 앱 → **새 보관함 만들기** → 이름 `PD` (iCloud 저장은 끄기)
2. 설정 → **커뮤니티 플러그인** → 제한 모드 끄기 → 찾아보기 → **Obsidian Git** 설치 → 활성화
3. Obsidian Git 설정 → **Authentication** 부분:
   - Username: `s1s1park`
   - Password/Personal access token: 0단계에서 복사한 열쇠 붙여넣기
4. 화면 아래 메뉴(또는 왼쪽 위 ☰) → **명령어 팔레트** → `Obsidian Git: Clone an existing remote repo` 실행
   - URL: `https://github.com/s1s1park/PD.git`
   - 폴더: 비워두기 (보관함 맨 위에 받기)
   - 이후 질문은 기본값으로 진행
5. 다 받아지면 옵시디언을 껐다 켜기
6. Obsidian Git 설정:
   - **Pull on startup**: 켜기
   - **Auto commit-and-sync interval**: `10` (분)
7. 설정 → **템플릿** 켜기 → 템플릿 폴더 위치: `템플릿`

> 핸드폰에서는 Git이 PC보다 조금 느려요. 영상은 Drive에 두고 리포에는 글만 두기 때문에 가볍게 유지돼요.

## 매일 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 최신 내용 받기 | 옵시디언을 켜면 자동. 수동으로는 명령어 팔레트 → `Obsidian Git: Pull` |
| 내가 고친 것 올리기 | 10분마다 자동. 바로 올리려면 명령어 팔레트 → `Obsidian Git: Commit-and-sync` |
| 새 대본 시작 | 새 노트 → 명령어 팔레트 → `템플릿 삽입` → `대본 템플릿` |
| 아이디어 적기 | `아이디어/아이디어 모음.md`에 한 줄 추가 |
| Claude에게 알리기 | "대본 고쳤어" / "체크리스트 체크했어" 라고 말하기 |

## 문제가 생기면

- **"충돌(conflict)"이 떴어요**: 같은 파일을 두 곳에서 동시에 고친 경우예요. 당황하지 말고 Claude에게 "옵시디언에서 충돌 났어"라고 말하세요.
- **토큰 오류**: 토큰이 만료됐을 수 있어요. 0단계를 다시 하고 새 토큰으로 바꾸세요.
