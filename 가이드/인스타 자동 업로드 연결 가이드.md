# 인스타 자동 업로드 연결 가이드

> 목표: Claude가 완성된 릴스를 **내 인스타 계정(팔로워 약 1천 명)**에 올리고, 조회수 같은 성과도 가져오게 하기.
> 비유: 스레드 연결할 때처럼 **"출입증(토큰)"**을 하나 받아서 Claude에게 맡기는 것. 비밀번호는 필요 없음.

## 준비물
- 핸드폰 인스타 앱 (올리고 싶은 계정으로 로그인)
- 컴퓨터 브라우저 (메타 개발자 페이지용. 스레드 앱 만들 때 쓴 계정 그대로)

---

## 1단계. 프로페셔널 계정으로 바꾸기 (핸드폰, 2분)
이미 "크리에이터"나 "비즈니스" 계정이면 건너뛰기.
1. 인스타 앱 → 프로필 → 오른쪽 위 ☰ → **계정 유형 및 도구** (또는 "크리에이터 도구 및 관리")
2. **프로페셔널 계정으로 전환** → **크리에이터** 선택 → 카테고리 아무거나 (예: "디지털 크리에이터")
- 팔로워·게시물은 그대로 유지됨. 무료. 언제든 되돌릴 수 있음

## 2단계. 메타 개발자 앱 만들기 (컴퓨터, 5분)
1. https://developers.facebook.com/apps 접속 → **앱 만들기**
2. 앱 이름: `릴스 자동화` (아무거나)
3. 사용 사례: **"Instagram에서 메시지 및 콘텐츠 관리"** 선택
   (영어면 "Manage messaging & content on Instagram")
4. 나머지는 기본값으로 → 앱 만들기 완료

## 3단계. 내 인스타 계정을 테스터로 추가 (컴퓨터 + 핸드폰)
> 앱을 "검수" 받지 않고 **내 계정에만** 쓰는 방법
1. 앱 화면 왼쪽 **앱 역할 → 역할** → **사람 추가** → **Instagram 테스터** → 내 인스타 아이디 입력
2. 핸드폰 인스타 앱 → 설정 → **웹사이트 권한 → 앱 및 웹사이트 → 테스터 초대** → **수락**
   (메뉴가 안 보이면 컴퓨터에서 instagram.com → 설정 → 앱 및 웹사이트 → 테스터 초대)

## 4단계. 출입증(토큰) 받기 (컴퓨터)
1. 앱 화면 왼쪽 **사용 사례 → Instagram → API 설정 (Instagram 로그인 사용)**
2. **"액세스 토큰 생성"** 칸에서 **계정 추가** → 인스타 로그인 → 권한 모두 허용
3. 계정 옆 **토큰 생성** 버튼 → 긴 글자(토큰)가 나옴 → **복사만 해 두기**
- ⚠️ 토큰은 **채팅창에 붙여넣지 말 것!** Claude가 띄우는 **보안 입력 창**에만 넣기
- 토큰은 약 60일짜리. Claude가 만료 전에 연장할 수 있음

## 5단계. Claude에게 맡기기
1. Claude에게 **"토큰 받았어"**라고 말하기
2. 화면에 뜨는 입력 창에 토큰 붙여넣기 → 저장
3. Claude가 연결 확인 (계정 이름·팔로워 수 읽어 보기만 함)

---

## 연결 후 규칙
- **올리기는 사용자가 "올려"라고 한 영상만.** 좋아요·댓글·팔로우·DM 등은 절대 안 함
- 하루 올릴 수 있는 개수 제한 있음 (넉넉함, 우리는 신경 쓸 일 없음)
- API로 올리면 **앱의 유행 음악은 못 붙임** → 음악이 중요한 편은 앱에서 직접 올리고, 성과 기록만 자동으로
