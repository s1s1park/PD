# 벤치마킹 2차 작업 지시 (PC 브라우저용)

> 이 파일은 사용자 PC의 Claude(데스크톱 앱 + 브라우저)가 읽고 실행하는 작업 지시서예요.

## 목표
인스타그램에서 **"헬스인의 하루 식비 1만원"**(싸게 단백질 체중×2 채우기)과 가까운 잘 된 릴스를 찾아서, 따라 할 포맷을 정리한다. 1차 결과는 `리서치/벤치마킹_1차.md`.

## 방법
1. 사용자가 로그인해 둔 브라우저로 인스타그램을 연다
2. 검색어: `자취식단` `고단백식단` `식비절약` `직장인루틴` `헬스식단` `자취생단백질` `가성비단백질` `직장인식단`
3. 각 검색 결과에서 **조회수가 팔로워 수보다 훨씬 높은 릴스**를 고른다 (목표 10~15개)
4. 영상마다 기록:
   - 계정, 팔로워 수, 조회수, 좋아요, 댓글 수, 링크
   - 첫 3초: 화면에 뭐가 나오고, 첫 문장(자막/말)이 뭔지
   - 구조: 초 단위로 장면 흐름 (예: 0-3s 결과 공개 / 3-10s 이유 / ...)
   - 사람이 나오는지(얼굴/손/목소리), 내레이션 유무, 자막 스타일, 음악
   - 캡션 첫 줄, 해시태그
   - 댓글에서 사람들이 반응한 포인트
5. 공통 패턴을 뽑아서 **따라 할 템플릿 2~3개**로 정리

## 지킬 것
- **보기만 한다.** 좋아요, 팔로우, 댓글, DM, 저장 등 계정에 흔적이 남는 행동은 하지 않는다
- 너무 빠르게 많이 넘기지 않는다 (인스타가 자동화로 의심하지 않게)
- 로그인 화면, 보안 확인 등이 나오면 멈추고 사용자에게 묻는다
